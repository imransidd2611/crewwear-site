Work uniform sizing for a trade crew

Custom orders are made to order, so a wrong size is hard to fix. A short sizing process prevents it.

Collect sizes before you order

  1. Ask each crew member for their usual shirt and hoodie size.
  2. Ask whether they prefer a looser fit for layering.
  3. Write sizes next to names in one list and send it with your logo.

Plan spares for growth

New hires and changes happen. Add a few spare pieces in the most common sizes so a new person can start in uniform on day one.

Check the size chart

Compare your crew with the size chart for each garment before you confirm. Ask us if you are unsure. We will help you choose sizes when you request your design.

Common questions

What if someone is between sizes?

For layering and work movement, most people size up. Ask for the size chart and compare measurements.

Can I reorder one extra size later?

Yes. Your approved design is kept so you can order more pieces to match.

Is sizing different for hoodies and long sleeves?

Fits differ by garment. Check the chart for each piece you order.
